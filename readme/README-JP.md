## ✨ 主な特徴

* **モダンな UI フレームワーク:** コンポーネントベースの開発を効率化する React を採用。
* **ユーティリティファーストのスタイリング:** 柔軟かつ迅速なデザイン調整を可能にする Tailwind CSS を統合。
* **型安全性:** TypeScript を使用して、コード品質を高め、実行時のエラーを最小限に抑える設計。
* **効率的な開発フロー:** 最適化されたビルドと高速なサーバー起動を実現する Rsbuild を採用。
* **アイコン統合:** Iconify を完全にサポートし、100+ のアイコンセットから 100,000+ のアイコンにアクセス可能です。
* **レスポンシブデザイン:** あらゆるデバイスサイズで動作する完全なレスポンシブレイアウトを作成するための組み込みユーティリティ。
* **ダークモードサポート:** Tailwind のカラースキームユーティリティを使用したネイティブダークモードの実装。
* **コード品質へのこだわり:** Antfu が提供する ESLint 設定を採用し、保守しやすいクリーンなコードを推奨。
* **高度な CSS 処理:** Tailwind CSS の PostCSS プラグインを統合し、高度なスタイル調整を実現。

## 🚀 始め方

プロジェクトをローカル環境で実行する手順を紹介します。

### 必要条件

以下のツールがインストールされていることを確認してください:
* Node.js (バージョン 18.x 以上を推奨)
* パッケージマネージャ（npm、yarn、または pnpm）
    ```bash
    node -v
    npm -v # または yarn -v または pnpm -v
    ```

### インストール

1. リポジトリをクローン:
    ```bash
    git clone https://github.com/Trapar-waves/react-tailwind.git
    cd react-tailwind
    ```
2. 依存関係をインストール:
    ```bash
    # お好みのパッケージマネージャを使用
    npm install
    # または
    yarn install
    # または
    pnpm install
    ```

## 🛠️ 使い方

インストールが完了したプロジェクトを実行・利用する方法を説明します。

### 使用可能なスクリプト

以下のスクリプトは `npm run`、`yarn`、または `pnpm` で実行可能です:
* `dev`: 開発用サーバーを起動し、ブラウザでアプリケーションを確認できます。
* `build`: 本番環境用の最適化されたビルドを生成します。
* `preview`: 生成された本番ビルドをローカルでプレビューするためのサーバーを起動します。

例:
```bash
# 開発用サーバーを起動
npm run dev

# 本番用ビルドを生成
npm run build
```
